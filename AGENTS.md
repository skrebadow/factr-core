# FACTR Core project

FACTR Core is the plugin maintained in this project and the product direction going forward. The sibling `factr.io` repository is a read-only reference unless the user explicitly authorizes changes there. Do not modify, publish, install over, or reuse FACTR's marketplace identity as part of ordinary Core work.

The runtime reasoning owner is `skills/factr-core/SKILL.md`. Keep one coherent behavioral methodology. Optional references supply genuinely conditional capabilities; avoid introducing mandatory stages, intermediate artifact schemas, universal approvals, or repeated policy loading for exploration.

Preserve the separation of source support, inference, hypotheses, unknowns, actual observations, and formal acceptance. Keep material trace links and assumptions durable in saved outputs. Claim anatomy and falsifiers must remain meaningful, not template paraphrases.

Evaluation files are development tools, not runtime prerequisites. Package and record validation do not demonstrate live reasoning quality or performance. Report measured results separately from hypotheses and constructed examples. Keep model, tools, scope, and budgets comparable when comparing Core with FACTR.

Use the standard-library checks described in README.md for changes to evaluation code. Run the skill-creator validator when changing skill frontmatter or instructions if it is available. Do not add tests that merely search for preferred instruction wording. Do not create auxiliary agents merely to cross a reasoning operation.
